# Het Wensbos 🌲

De verlanglijsten van familie Annema & Bos, als 8-bit spelletje.
Live: https://studioannema.github.io/wensbos/

## Een wens toevoegen

1. Open je eigen bestand in de map [`wensen/`](wensen/) (bijv. `wensen/tijme.md`).
2. Klik rechtsboven op het potloodje ✎ (bewerken).
3. Zet er per wens één regel bij:

   ```
   - Titel | prijs | link | notitie
   ```

   Alleen de titel is verplicht. Begin met `★` als je iets héél graag wilt:

   ```
   - ★ Nieuwe koptelefoon | €80 | https://www.voorbeeld.nl | in het zwart graag
   - Boek over bomen | €25
   ```

4. Klik op **Commit changes**. Binnen een minuutje staat het in het bos.

Iets gekregen of wil je het niet meer? Haal de regel gewoon weg.
